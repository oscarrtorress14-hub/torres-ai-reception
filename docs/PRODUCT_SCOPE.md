# Alcance

## Propuesta
Recepcionista virtual para atender consultas por voz y WhatsApp, registrar solicitudes, consultar agenda conectada y derivar casos a una persona.

## Incluido en esta demo
- Empresa ficticia, servicios, horarios y FAQ.
- API para registrar solicitudes pendientes.
- Registro de interacciones simuladas.
- Informe de actividad para propietario.

## No implementado
IA conversacional, telefonía, WhatsApp Business Platform, calendarios, panel web, autenticación de producción, PostgreSQL o despliegue cloud.

## Regla crítica
Nunca inventar precios, horarios o disponibilidad. No confirmar una cita hasta consultar una agenda real y recibir confirmación inequívoca.
